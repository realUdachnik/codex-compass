# Установка Codex Compass

Нужны Python 3.11 или новее и Linux либо macOS. В Windows используйте Linux-среду WSL. Для карты проекта достаточно Python; для работы исполнителя нужен установленный и настроенный Codex.

## Самый простой способ

1. Скачайте ZIP Codex Compass и распакуйте его.
2. Откройте полученную папку в Codex и скажите:

   > Установи этот навык. Прочитай INSTALL_RU.md и выполни python3 install.py. Затем проверь установку командами context и doctor через установленный scripts/compass.py.

Установщик положит навык в `$CODEX_HOME/skills/codex-compass`, если задан `CODEX_HOME`, иначе — в `~/.codex/skills/codex-compass`. Настройки модели, ключи и другие навыки он не меняет. Откройте новую сессию Codex, чтобы новый навык появился в списке.

Внутри установленной папки есть и инструкции, и сама программа. Исходный проект, `pip`, доступ к сети и сторонние Python-библиотеки для установки не нужны. Распакованный архив после установки можно удалить.

## Установка командой

Из распакованной папки:

```bash
python3 install.py
```

Для отдельной папки, в том числе с пробелами:

```bash
python3 install.py --target "/путь с пробелами/skills/codex-compass"
```

Проверка установленной программы:

```bash
python3 "/путь с пробелами/skills/codex-compass/scripts/compass.py" context --workspace "/путь к вашему проекту"
python3 "/путь с пробелами/skills/codex-compass/scripts/compass.py" doctor
```

`context` показывает карту проекта. `doctor` проверяет наличие Codex и сообщает, чего не хватает; он не обращается к модели. Если Codex не установлен, карта проекта работает, а `doctor` сообщает об отсутствии исполнителя.

## Повторная установка и обновление

Ту же команду можно выполнить повторно. Неизменённая установка останется на месте. Новая версия заменит только файлы, которые ранее поставил этот установщик.

Если папка уже занята другим навыком, является ссылкой или содержит ваши изменения, установщик остановится и сохранит её. Для проверки нового комплекта можно выбрать другую папку через `--target`. Не копируйте новый комплект поверх чужих файлов вручную.

## Напоминания во время долгой задачи

В версии 0.4 есть отдельный режим наблюдения. Обычная установка навыка даёт
памятку; для программного контроля во время работы используется команда assist.
Можно попросить Codex:

> Запусти эту задачу в режиме напоминаний по references/reminders.md. Используй
> указанную мной модель и высокий уровень размышления. Передай исполнителю всю
> мою задачу и существующие ограничения.

Прямая команда через установленный навык:

```sh
python3 /путь/к/codex-compass/scripts/compass.py assist --workspace /путь/к/проекту --goal 'Что нужно сделать' --model gpt-6.1-sol --reasoning high
```

Модель в примере можно заменить. Если не указывать model/reasoning, действуют
настройки терминального Codex; они могут отличаться от выбранного в другом чате.
Исполнитель получает полную памятку. Наблюдатель иногда добавляет короткое
напоминание по видимым действиям и после сокращения контекста. Предел — четыре
напоминания на сессию. Он не умеет читать мысли или гарантировать, что модель
всегда помнит все правила; результат всё равно нужно проверять.

После настоящего сокращения контекста доставка напоминания проверена отдельно.
При подсчёте расхода есть оговорка: итоговый счётчик этой версии Codex может не
включать отдельный вызов для сокращения контекста. Программа сохраняет известные
числа и прямо отмечает неполную запись, вместо того чтобы показывать точную цену.

Настройки и доверие к точным собственным обработчикам действуют только для этого
запуска. Если в проекте уже есть другие обработчики, режим явно остановит
подготовку, сохранив их. Проверена поддержка Codex CLI 0.171.0; другая версия должна
пройти ту же проверку возможностей. Обычное использование установленного навыка
доступно отдельно от режима наблюдения.

Модель и разрешения берутся из настроек терминального Codex; отдельный запуск
не умеет угадывать более строгие настройки другого чата. Существующие ограничения
задачи нужно передать исполнителю и соблюдать.
