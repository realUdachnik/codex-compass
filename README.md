# Codex Compass

Навык для Codex, который помогает разобраться в незнакомом проекте, найти связанные места, выбрать подходящее решение и проверить результат. Для долгой работы есть отдельный режим коротких напоминаний.

**[Скачать готовый навык 0.4.0](https://github.com/realUdachnik/codex-compass/releases/download/v0.4.0/codex-compass-0.4.0.zip)** · [Все выпуски](https://github.com/realUdachnik/codex-compass/releases)

## Установка за три шага

1. Скачайте ZIP по ссылке выше и распакуйте его.
2. Откройте полученную папку в Codex и напишите:

   > Установи этот навык. Прочитай INSTALL_RU.md, выполни python3 install.py и проверь установку командами context и doctor.

3. Откройте новую сессию Codex и напишите:

   > Используй $codex-compass. Вот моя задача: …

Нужны **Python 3.11 или новее**, **Linux или macOS** и настроенный Codex. На Windows используется Linux-среда WSL. Установка использует встроенные средства Python.

Если скачали весь проект через **Code → Download ZIP** или скопировали его на сервер, порядок тот же: откройте папку с `install.py` и следуйте этим трём шагам. [Подробная инструкция](INSTALL_RU.md).

## Что делает навык

- Помогает найти нужные файлы, связанные вызовы и похожие решения в проекте.
- Предлагает соразмерить выбор решения с задачей: важные последствия стоит проверить заранее, простая правка требует меньше подготовки.
- Напоминает проверить новую возможность и важное старое поведение.
- Предлагает исправлять причины существенных сбоев и заканчивать работу, когда важные требования выполнены.

Пример просьбы:

> Используй $codex-compass. Добавь выгрузку обращений в CSV. Сохрани существующие права доступа и проверь выгрузку на большом списке.

## Напоминания для долгой работы

Обычная установка добавляет навык. Для наблюдения за ходом долгой задачи попросите Codex отдельно:

> Запусти эту задачу в режиме напоминаний по references/reminders.md. Используй выбранную мной модель и уровень размышления. Передай исполнителю всю мою задачу и ограничения.

Наблюдатель смотрит на видимые действия. Например, после проверки код снова изменился или давно идут правки без распознанной проверки. Он может отправить короткое напоминание о цели и проверке результата.

Общий предел — четыре сообщения за сессию. Обычные напоминания могут занять до трёх мест; одно место зарезервировано для сокращения контекста. Между обычными сообщениями — минимум шесть действий. Отдельная модель для наблюдателя не вызывается. Доставка сообщения после сокращения контекста проверена отдельным опытом; улучшение качества работы после такого события пока не доказано.

Режим напоминаний проверен с **Codex CLI 0.171.0**. Поддержку другой версии программа проверяет перед запуском. Подробности: [режим напоминаний](payload/codex-compass/references/reminders.md).

## Что показала проверка

Пять сложных доработок существующих программ, три модели, три режима: без навыка, с навыком, с навыком и напоминаниями. Всего **45 исходных и 9 отдельных контрольных работ**; везде высокий уровень размышления.

Все 54 программы прошли выбранные независимые проверки. **Рост качества на этих заданиях не обнаружен.** Время и расход зависели от задачи и модели: встречались как меньшие, так и большие затраты. Один запуск каждого сочетания не доказывает устойчивого преимущества.

В исходной серии обнаружены пересечения временных файлов. Они раскрыты в отчёте; сравнение без затронутых троек показано отдельно. Девять новых контролей проведены с раздельными временными пространствами и не подменяют исходные результаты. В этих 54 работах естественных сокращений контекста не было, поэтому пользу напоминаний именно после такого события серия не измеряла.

- [PDF: объяснение, графики, задания и все 54 ответа](https://github.com/realUdachnik/codex-compass/releases/download/v0.4.0/codex-compass-comparison-2026-11-23.pdf).
- [Полный архив сравнения и исходников выполненных работ](https://github.com/realUdachnik/codex-compass/releases/download/v0.4.0/codex-compass-comparison-2026-11-23.zip).

Навык задаёт полезный порядок работы; способности самой модели остаются прежними. Сравнение с Claude не проводилось.

## Файлы проекта

- `install.py` — установщик.
- `payload/codex-compass/SKILL.md` — сама памятка.
- `payload/codex-compass/runtime/codex_compass/` — полный исходный код программы.
- `payload/codex-compass/references/` — инструкции для дополнительных режимов.
- `bundle-manifest.json` — перечень и контрольные суммы устанавливаемых файлов.
- `RELEASE_MANIFEST.json` — контрольные суммы опубликованных архивов.

Исполняемый код и установщик соответствуют проверенному комплекту 0.4.0. В инструкции этой страницы убран раздел сборки из отдельного дерева разработки; прикреплённый ZIP навыка сохранён без изменений.
